Welcome! This is a small demonstration book built with [MyST Markdown](https://mystmd.org) and the default `book-theme`.

## What's inside

- **Chapter 1: Foundations** covers admonitions, figures, inline and display math, and pipe tables.
- **Chapter 2: Going Further** covers dropdown admonitions, list tables, cross-chapter references, and a page you can download as a PDF.

## How to read it

Use the table of contents on the left to move between chapters. Each page has an **On This Page** outline on the right. The buttons at the top of each page link to its source on GitHub and to any downloads.
